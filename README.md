# TC-2026-Elemental-Battle

## Resumo 
Durante a disciplina de Tópicos em Computação fomos desafiados a criar um jogo 2D utilizando C++ ou outra linguagem de preferencia da equipe.

## Sobre o jogo
  O Jogo Elemental Battle é inspirado nas mecânicas classicas de Pokemon, no qual possui batalhas táticas por turno, cada personagem possui caracteristicas próprias como:
   - Vida
   - Dano
   - Elemento/Ataque principal
   - Defesa
   - Fraqueza
  Ademais, assim como Pokemon durante o jogo Elemental Battle o jogador terá possibilidade de fortalecer suas cartas elevando seu nível.

## Tecnologias utilizadas 

 ° Python
 ° Pygame 
 ° Box2D
