ESTRUTURA DO PROJETO – ELEMENTAL BATTLE

Este documento define a organização do código do projeto e explica a responsabilidade de cada pasta.
Todos os integrantes da equipe devem seguir esta estrutura para manter o projeto organizado.

---

PASTA: meu_jogo/
Pasta raiz do código do jogo.

Arquivo principal:
main.py

Responsabilidade:

* Ponto de entrada do jogo.
* Inicializa o player, Game, MapManager e GameManager.

Regras:

* Não colocar lógica de batalha aqui.
* Não colocar lógica de mapas ou XP aqui.
* O main deve apenas iniciar o sistema do jogo.

---

PASTA: meu_jogo/core/
Responsável pela infraestrutura do jogo (motor do jogo).

Arquivos e responsabilidades:

game_manager.py

* Inicializa pygame, cria a janela, controla o loop principal.
* Loop principal: eventos → update → render.

scene_manager.py

* Gerencia qual cena está ativa. Permite trocar de cena.

config.py

* Constantes globais: tamanho da janela (800x500), FPS, título, cores, XP.

game_state.py

* Enum de estados globais: MENU, TRAINING, BATTLE, GAME_OVER, GAME_COMPLETE.

game_scene.py

* Classe base abstrata para todas as cenas (handle_event, update, draw).

game.py

* Controla progressão global da campanha.
* Rastreia bosses derrotados (defeated_bosses).
* Define GAME_COMPLETE quando todos os 5 bosses forem derrotados.

battle.py

* Gerencia batalha entre dois personagens.
* execute_player_action / choose_enemy_action / execute_enemy_action / is_over / get_winner.

map.py

* Stage: estrutura base de mapa.
* Map: mapa baseado em tiles com câmera lerp e suporte a bg_image.
* Reexporta todas as classes de tile de core/tiles/ para compatibilidade de imports.

map_manager.py

* Carrega mapas sob demanda (cache), processa troca de mapa via portais.

map_builder.py

* build_themed_room: gera matriz 12×10 de sala de batalha.
* make_room_tiles: combina dicts de tile globais + específicos da sala.

elements.py

* element_advantage: tabela de vantagens elementais.
* ELEMENT_NAMES_PT: nomes PT-BR dos elementos.
* ELEMENT_COLORS: cores canônicas por elemento (fonte única para menu e batalha).
* calculate_damage: dano considerando elemento e fraqueza.

Subpasta: core/tiles/
* Todas as classes de tile, organizadas por tema:
  base.py          — Tile (classe raiz)
  terrain.py       — GrassTile, WallTile, FlowerGrassTile, BushTile, TreeTile
  water_tiles.py   — WaterTile, IceTile, CrystalTile, RiverTile...
  fire_tiles.py    — FireTile, LavaTile, HotRockTile, EmberTile...
  wind_tiles.py    — WindTile, CloudTile, SkyPathTile, FeatherTile...
  electric_tiles.py — SandTile, MetalTile, CircuitFloorTile, NeonBorderTile...
  shadow_tiles.py  — VoidFloorTile, ShadowCrystalTile, DarkMistTile
  arena_tiles.py   — IceArenaTile, VolcanoFloorTile, SkyArenaTile, MetalArenaTile
  path_tiles.py    — StoneRoadTile, WoodPathTile, WoodBridgeTile
  portal.py        — PortalTile

Regras:

* Não colocar sprites ou imagens aqui.
* Não colocar dados específicos de inimigos aqui.
* Não colocar lógica de renderização de cenas aqui.

---

PASTA: meu_jogo/cenas/
Responsável pelas telas do jogo.

Arquivos principais:

menu_scene.py       — Tela inicial + seleção de elemento (MenuScene)
campo_de_treino.py  — Overworld 2D top-down (CampoDeTreinoScene)
battle_scene.py     — Tela de batalha por turnos (BattleScene)
game_over_scene.py  — Tela de derrota (GameOverScene)
victory_scene.py    — Tela de vitória final (VictoryScene)

Subpasta: cenas/battle/
* Componentes visuais da batalha:
  character_object.py — sprite + animações do personagem na batalha (CharacterObject)
  projectile.py       — projétil animado com callback on_hit (Projectile)
  constants.py        — reexporta ELEMENT_COLORS e _to_rgb

Regras:

* Cenas controlam o que aparece na tela.
* Cenas podem usar objetos do core e entidades.
* Cenas não devem implementar regras de dano ou XP diretamente.

---

PASTA: meu_jogo/entidades/
Responsável pelos objetos do jogo.

Arquivos:

character.py

* Classe base Character: hp, dano, defesa, elemento, fraqueza, nível, xp.
* take_damage, gain_xp, level_up, is_alive.

acoes.py

* Hierarquia de ações: Action → AttackAction, SpecialAttackAction, DefendAction, HealAction.
* Cada ação tem execute(attacker, defender) → dict.

ai_entidade.py

* BasicAI — IA simples para inimigos genéricos.

smart_ai.py

* SmartAI — IA dos bosses (escolha adaptativa de ação).

Regras:

* Entidades representam objetos do jogo.
* Entidades guardam estado e regras.
* Entidades não devem desenhar na tela diretamente.

---

PASTA: meu_jogo/data/
Responsável por dados do jogo.

Arquivos:

characters_data.py

* Bosses do mundo aberto: hydra, thunder_beast, storm_eagle, magma_titan, shadow_lord.
* ROOM_BOSS: mapeamento sala → boss.
* reset_boss: utilitário para restaurar HP do boss.

maps_data.py

* Matrizes de tile para todos os mapas (MUNDO_ABERTO + 5 salas de batalha).
* ALL_MAP_DATA: dict com dados de todos os mapas (consumido pelo MapManager).

Regras:

* Esta pasta contém apenas dados.
* Não colocar lógica complexa aqui.

---

PASTA: meu_jogo/midia/
Responsável pelos arquivos de mídia do jogo.

midia/sprites/
* sprite_factory.py    — pixel art programática (matrizes 16×16 + palette)
* animated_sprite.py   — AnimatedSprite (frame-a-frame)
* tile_sprites.py      — sprites de tiles (cache, get_tile_sprite)

midia/sfx/, midia/music/   — gerados em runtime pelo AudioManager

Regras:

* Não colocar lógica de jogo aqui.

---

PASTA: meu_jogo/testes/
Responsável por testes e protótipos.

Arquivos aqui não fazem parte do jogo final.

---

REGRAS GERAIS DO PROJETO

1. main.py deve ser simples — apenas inicializa e inicia.
2. core controla o funcionamento do jogo.
3. cenas controlam telas e renderização.
4. entidades representam personagens e ações.
5. data guarda definições prontas de inimigos e mapas.
6. midia guarda sprites, sons e músicas.
7. testes guarda scripts de prototipagem.

Seguir esta estrutura ajuda a manter o projeto organizado e facilita o desenvolvimento em equipe.

---

Como Jogar:

1. rode o comando "pip install pygame" no terminal para instalar a biblioteca necessária.
2. rode o comando "python -m meu_jogo.main" no terminal para rodar o jogo.
