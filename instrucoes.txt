ESTRUTURA DO PROJETO – ELEMENTAL BATTLE

Este documento define a organização do código do projeto e explica a responsabilidade de cada pasta.
Todos os integrantes da equipe devem seguir esta estrutura para manter o projeto organizado.

---

PASTA: meu_jogo/
Pasta raiz do código do jogo.

Arquivo principal:
main.py

Responsabilidade:

* Ponto de entrada do jogo.
* Deve apenas inicializar o GameManager.
* Definir a cena inicial do jogo.

Regras:

* Não colocar lógica de batalha aqui.
* Não colocar lógica de mapas ou XP aqui.
* O main deve apenas iniciar o sistema do jogo.

---

PASTA: meu_jogo/core/
Responsável pela infraestrutura do jogo (motor do jogo).

Aqui ficam as partes responsáveis por controlar o funcionamento geral do jogo.

Arquivos e responsabilidades:

game_manager.py

* Inicializa bibliotecas (pygame).
* Cria a janela do jogo.
* Controla o loop principal do jogo.
* Loop principal:
  eventos → update → render.
* Controla FPS.
* Controla encerramento do jogo.

scene_manager.py

* Gerencia qual cena está ativa no momento.
* Permite trocar de cena.

Exemplos de troca de cena:
menu → treino
treino → batalha
batalha → vitória
batalha → game over

config.py

* Guarda configurações globais do jogo.

Exemplos:

* tamanho da janela (500x500)
* FPS
* título da janela
* XP por nível
* incrementos de atributos por nível

game_state.py

* Define os estados globais do jogo.

Exemplos:
MENU
BATTLE
MAP_COMPLETE
GAME_OVER
GAME_COMPLETE

battle.py

* Controla o sistema de batalha.
* Executa ações do jogador.
* Executa turno do inimigo.
* Verifica quando a batalha termina.
* Define o vencedor.

game.py

* Controla o fluxo geral do jogo.
* Controla progressão entre mapas.
* Inicia novas batalhas.
* Gerencia vitória e derrota.

map.py

* Define a estrutura de um mapa do jogo.
* Cada mapa possui:

  * nome
  * lista de inimigos
  * boss

elements.py

* Sistema elemental do jogo.
* Define vantagem entre elementos.
* Calcula dano considerando elemento e fraqueza.

Regras importantes:

* Não colocar sprites ou imagens aqui.
* Não colocar dados específicos de inimigos aqui.
* Não colocar lógica de renderização de cenas aqui.

---

PASTA: meu_jogo/cenas/
Responsável pelas telas do jogo.

Cada arquivo nesta pasta representa uma cena ou tela.

Exemplos de cenas:

* menu
* campo de treino
* batalha
* vitória
* game over

Arquivos principais:

base_cenas.py

* Classe base para todas as cenas.
* Define estrutura comum das cenas.

campo_de_treino.py

* Cena inicial do jogo.
* Campo de treinamento com espantalho.
* Usada para ensinar as mecânicas básicas.

Subpastas:

cenas/imagens/

* Imagens usadas apenas pelas cenas.

cenas/sons/

* Sons usados apenas pelas cenas.

Regras:

* Cenas controlam o que aparece na tela.
* Cenas podem usar objetos do core e entidades.
* Cenas não devem implementar regras de dano ou XP.

---

PASTA: meu_jogo/entidades/
Responsável pelos objetos do jogo.

Aqui ficam os elementos que participam diretamente do jogo.

Arquivos:

character.py

* Classe base de personagem/criatura.
* Atributos:
  nome
  hp
  dano
  defesa
  elemento
  fraqueza
  nível
  xp

acoes.py

* Define ações que personagens podem executar.
* Exemplo:
  AttackAction

ai.py

* Define comportamento da inteligência artificial.
* Exemplo:
  BasicAI

Regras:

* Entidades representam objetos do jogo.
* Entidades guardam estado e regras.
* Entidades não devem desenhar na tela diretamente.

---

PASTA: meu_jogo/data/
Responsável por dados do jogo.

Aqui ficam definições prontas usadas pelo jogo.

Arquivos:

characters_data.py

* Define inimigos e personagens.

Exemplo:
slime
goblin
wolf
forest_guardian

maps_data.py

* Define mapas do jogo.
* Define lista de inimigos de cada mapa.
* Define boss do mapa.

Regras:

* Esta pasta contém apenas dados.
* Não colocar lógica complexa aqui.

---

PASTA: meu_jogo/midia/
Responsável pelos arquivos de mídia do jogo.

Sugestão de organização:

midia/sprites/

* sprites de personagens
* sprites de cenário

midia/sfx/

* efeitos sonoros

midia/music/

* músicas

midia/fonts/

* fontes usadas no jogo

Regras:

* Não colocar código aqui.
* Apenas arquivos de mídia.

---

PASTA: meu_jogo/utils/
Responsável por utilidades reutilizáveis.

Exemplos:

* funções matemáticas auxiliares
* helpers de desenho
* constantes de cores
* ferramentas de debug

---

PASTA: meu_jogo/testes/
Responsável por testes e protótipos.

Arquivos aqui não fazem parte do jogo final.

Exemplo:
teste_movimentacao.py

Objetivo:

* testar mecânicas
* testar movimentação
* testar ideias rapidamente

---

REGRAS GERAIS DO PROJETO

1. main.py deve ser simples.
2. core controla o funcionamento do jogo.
3. cenas controlam telas e renderização.
4. entidades representam personagens e objetos do jogo.
5. data guarda definições prontas de inimigos e mapas.
6. midia guarda sprites, sons e músicas.
7. utils guarda funções auxiliares.
8. testes guarda scripts de prototipagem.

Seguir esta estrutura ajuda a manter o projeto organizado e facilita o desenvolvimento em equipe.

---

***Como Jogar:

1. rode o comando "pip install pygame" no terminal para instalar a biblioteca necessária.
2. rode o comando "python -m meu_jogo.main" no terminal para rodar o jogo.
